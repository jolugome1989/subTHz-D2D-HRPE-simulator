This folder provides a full sub-THz D2D simulator based on measurement data. The measurement data were analyzed using RiMax, a High Resolution Parameter Extraction (HRPE) algorithm, where the multipath (MPC) and diffuse multipath (DMC) components were extracted and statistically modeled.  

Parameter extraction and modeling are based on HRPE (RiMax). The code generates a synthetic channel based on the statistical models obtained from the MPC+DMC.
